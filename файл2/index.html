    Продвинутые настройки: свой сигнальный брокер
    Брокер используется ТОЛЬКО для поиска устройств и сигналинга — файлы идут напрямую (P2P) и зашифрованы. Поднимается одной командой (Docker):
    docker run -d --name emqx -p 8083:8083 -p 8084:8084 emqx/emqx
    затем впишите wss://ваш-домен:8084/mqtt. Все устройства канала должны использовать один брокер.
    Диагностика соединения
    FileBridge · файлы передаются напрямую между устройствами (P2P/WebRTC) и нигде не хранятся.
    Двойная защита: шифрование канала WebRTC (DTLS) + сквозное шифрование файлов (AES-256-GCM, ключ выводится из кодов устройств и адреса канала).
    Обрыв связи — передача возобновляется с места обрыва.
