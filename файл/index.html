        Продвинутые настройки: свой сигнальный брокер
        Свой брокер = максимальная надёжность. Поднимается одной командой (Docker):
        docker run -d -p 8084:8084 emqx/emqx
        затем впишите wss://ваш-домен:8084/mqtt (TLS — через Caddy/nginx). Оба устройства должны использовать один брокер.
        FileBridge · файлы передаются напрямую (P2P/WebRTC, шифрование DTLS) и нигде не хранятся.
        Оба устройства должны быть онлайн одновременно. Видео не поддерживаются.
