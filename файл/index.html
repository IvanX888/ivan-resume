        Продвинутые настройки: свой сигнальный брокер
        Публичные брокеры могут быть недоступны из мобильных сетей (провайдеры режут нестандартные порты). Свой брокер = максимальная надёжность. Поднимается одной командой (Docker):
        docker run -d --name emqx -p 8083:8083 -p 8084:8084 emqx/emqx
        затем впишите wss://ваш-домен:8084/mqtt (TLS — через Caddy/nginx, см. readme). Оба устройства должны использовать один брокер.
        Диагностика соединения
        FileBridge · файлы передаются напрямую (P2P/WebRTC, шифрование DTLS) и нигде не хранятся.
        Оба устройства должны быть онлайн одновременно. Обрыв связи — передача автоматически возобновляется с места обрыва.
