# Помощник специалиста по закупкам — архитектура «каркас + данные»

## Идея

Система разделена на две части:

| Часть | Где лежит | Что внутри |
|---|---|---|
| **Каркас** (`Помощник_закупок_КАРКАС_v3.6.html`) | GitHub (открытый репозиторий) | Весь код, интерфейс, движок закона РБ (ПП № 168 ред. № 355, Закон № 419-З, пороги в БВ на 2026 г.). Без чужих данных. |
| **Данные** (`Данные_организации.json`) | Локально у каждой организации (компьютер → позже сервер в сети) | Профиль организации (реквизиты, внутренний Порядок/ЛПА, лимиты), база поставщиков, сделки, журнал, задачи. |

Закон один для всех → зашит в каркас. Внутренние порядки и специфика организаций разные → живут в профиле JSON.

## Как это работает сейчас (этап 1 — браузер)

1. Скачайте каркас (один HTML-файл, работает офлайн, без установки).
2. Откройте в браузере → **СИСТЕМА → Данные и бэкап**.
3. Загрузите JSON своей организации: «Восстановить из копии» (полный пакет) или «Загрузить профиль» (только реквизиты/ЛПА).
4. Работаете. Все данные — в localStorage браузера, никуда не отправляются.
5. Раз в неделю: «Скачать резервную копию» — это и есть ваша база данных в JSON.

## Этап 2 — несколько закупщиков (сеть/сервер)

JSON-формат уже готов: тот же файл можно положить на сервер и синхронизировать
(сейчас — обмен файлом, позже — API поверх того же JSON: `sup`, `deals`, `zlog`,
`tasks`, `org`, `sign` и т.д.). Менять код каркаса не потребуется.

## Этап 3 — продажа доступа

Каждая организация получает: каркас (общий, с GitHub) + свой JSON-профиль.
Данные клиента хранятся у клиента — в браузере/на его сервере. Обновления закона
выкатываются новой версией каркаса, данные не трогаются.

## Формат пакета данных (JSON)

```json
{
  "app": "Pomoshchnik zakupok — DATA PACK",
  "ver": "3.6",
  "org":   { "ORG": "...", "ORG_UNP": "...", "ORG_BANK": "...", "LIM9": 5000 },
  "sup":   [ /* поставщики: name, group, email[], phone[], site[], unp, verified */ ],
  "deals": [ /* сделки: sup, subj, sum, point (пункт постановления), stage, date */ ],
  "zlog":  [ /* журнал закупок */ ],
  "tasks": [], "cases": [], "checks": {}
}
```

## Обновление каркаса

1. Экспортировать данные из старой версии («Скачать резервную копию»).
2. Открыть новую версию каркаса.
3. Импортировать данные («Восстановить из копии»). Готово.
